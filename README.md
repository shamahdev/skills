# Skills

Installable agent skills.

[![skills.sh](https://skills.sh/b/shamahdev/skills)](https://skills.sh/shamahdev/skills)

## Install

```bash
npx skills add shamahdev/skills
```

Install one skill:

```bash
npx skills add shamahdev/skills@call-graph
```

## Skills

### call-graph

Use when showing call graphs, execution flows, or architecture traces. Enforces consistent plain-text output and Effect A/E/R graph thinking.
