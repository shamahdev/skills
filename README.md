# shamahdev/skills

A curated, mix-and-match set of agent skills I use in my daily workflow. Most of them are not adapted, or distilled from other skill repos, notes, and workflows, then kept here as a collection.

## Install

```bash
npx skills add shamahdev/skills
```

Install one skill:

```bash
npx skills add shamahdev/skills@call-graph
```

## Skills

### call-graph

Use when showing call graphs, execution flows, or architecture traces.
